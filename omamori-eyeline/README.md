# おまもりアートメイク アイラインスクール《冬季》— 営業提案用デモLP

PURPOSE制作の**非公式デザイン提案（デモ）**です。公式サイトではありません。

- 依存なしの静的HTML（`index.html` / `assets/css/style.css` / `assets/js/main.js`）
- フォントのみ Google Fonts（Cormorant Garamond / Noto Sans JP / Noto Serif JP）
- `noindex, nofollow`（meta、`robots.txt`、`_headers` の X-Robots-Tag）
- 計測タグ・Cookie・フォーム・申込処理は**なし**。最終CTAは既存のnote募集ページへのリンクのみ

ローカル確認：`index.html` をブラウザで開くだけ。
